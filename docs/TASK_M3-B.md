## 3. 🔴 红线

1. **不得用 iframe**（本项目就是要取代旧 iframe 方案）
2. **XSS**：复用 `cs-core.js` 的 `escapeHtml`，**不得新写一份**；模型文本一律经 `textContent` 或其转义路径
3. **商品卡片数据来自 `tool` 事件**（不从 LLM 文本解析）
4. **`footer.html` 只追加不改坏**：它是全站共用模板，改坏会影响所有页面 → 改完必须跑冒烟 16/16
5. **浮窗不得自动打开**（只在用户点击后出现），避免干扰商品浏览

## 4. 已知的坑（第一步踩过，别重蹈）

| 坑 | 说明 |
|---|---|
| **`th:replace` 会替换整个 `<head>`** | 在模板里额外写的 `<link>` / `<script>` 会被**静默丢弃** → 样式必须走 `cs.css` 的 `@import`；脚本要么走 footer 注入，要么确认 head 片段机制 |
| **卡片被流式文本抹掉** | 不要把 delta 写到与卡片同一层容器（`textContent` 赋值会清空子节点）；文本要用独立子元素 |
| **`done` 不是终止事件** | 客户端只在收到 `review` 或连接关闭后停止读取（DESIGN §4.2） |

## 5. 交互规格（§8.1）

- 触发器：右下角固定圆形按钮（含未读提示可选）；点击展开 380×560 面板
- 面板结构：头部（含「当前咨询商品」）+ 消息区 + 输入区 + 3 条快捷 chips
- 「**展开完整页**」按钮 → 跳 `/cs?goodsId=<当前上下文>`
- 浮窗内的会话独立于 `/cs` 页（各自 `conversationId`），**但都要持久化到 localStorage**（跨刷新保留）
