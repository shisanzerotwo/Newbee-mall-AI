# 新蜂商城前端重设计规格 v3 · ONYX

> 状态：**预览待确认**（2026-10-08）· 预览文件：`docs/redesign/preview.html`
> 本文件是 v3 落地的唯一视觉依据。确认方向后，所有 CSS / 模板改动必须能回溯到本文的 token 与组件规范。
> 前身：`docs/MALL-UI-SPEC.md`（v1/v2「清爽极简 · 青绿」）。v3 是**换方向**，不是迭代 —— v1/v2 的 token 体系整体作废，但**信息架构、DOM 结构、类名约定全部保留**。

---

## 1. 设计方向

| 项 | 内容 |
|---|---|
| 名称 | **ONYX（曜石）** |
| 关键词 | 深色优先 · 高对比 · 商品图发光 · 单一强调色 · 大圆角 + 细描边 |
| 氛围词 | 沉、锐、克制、专业。参考气质：深色开发者工具 / 高端 3C 电商 |
| 核心主张 | 商城与 AI 客服共用一套 token。客服不是嵌进来的外部页面，而是这套视觉里的**原生能力** |

### 与 v1/v2 的关键差异

| 维度 | v1/v2（旧） | v3（ONYX） |
|---|---|---|
| 底色 | 冷灰白 `#f6f8f9` | 深墨 `#0A0B0F`（默认），浅色为可选 |
| 品牌色 | 青绿 `#1baeae` | 电光紫 `#6D5BFF` |
| 价格色 | 橙 `#e8590c` | 暖橙 `#FF7A3D`（更亮，深底上可读） |
| 圆角 | 卡片 8 / 按钮 6 | 卡片 18 / 面板 14 / 按钮 10 |
| 层次手法 | 柔影 `0 8px 24px` | **1px 细描边** 为主，阴影只用于浮层 |
| 主题 | 6 套（青碧/暖金/靛蓝/暗夜/莓果/墨绿） | 收敛为 **深 / 浅 2 套**（保留扩展位） |
| 动效 | fade-up 滚动浮现、交错延迟 | 收敛为 hover 位移 + 描边变色，**去掉滚动入场动画** |

### 保留不动的部分（重要）

- 模板 DOM 结构与 Thymeleaf 片段（`header` / `footer` / `nav` 三个 fragment）
- 类名约定：`.w` / `.fl` / `.fr` / `.clearfix` / `.mt20` 等工具类**保留类名换实现**
- `cs-core.js` 的事件契约（`onStage` / `onRag` / `onTool` / `onDelta` / `onDone` / `onReview` / `onError` / `onFinish`）与 DOM 类名（`cs-msg` / `cs-panel` 等）
- 任何 Java 代码、Controller、jqGrid 列定义、wangEditor、上传逻辑、商品图数据

## 2. 色彩系统

### 深色主题（默认）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0A0B0F` | 页面底 |
| `--bg-1` | `#12141A` | 卡片 / 面板 |
| `--bg-2` | `#1A1D25` | 输入框 / 悬浮态 |
| `--bg-3` | `#22262F` | 标签底 / 三级面 |
| `--bd` | `#262A35` | 描边（默认） |
| `--bd-2` | `#363B49` | 描边（强调 / hover） |
| `--t1` | `#EDEFF4` | 主文字 |
| `--t2` | `#9BA3B2` | 次要文字 |
| `--t3` | `#666E7E` | 辅助 / 占位 |

### 品牌与语义色

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--brand` | `#6D5BFF` | `#5B48F0` | 主按钮、导航激活、品牌标识 |
| `--brand-hi` | `#8B7CFF` | `#7A68FF` | hover、链接强调 |
| `--brand-dim` | `rgba(109,91,255,.14)` | `rgba(91,72,240,.10)` | 选中底、标签底 |
| `--price` | `#FF7A3D` | `#E8590C` | 价格、促销标签、立即购买 |
| `--ok` | `#34D399` | `#0F9D63` | 现货、质检通过 |
| `--warn` | `#FBBF24` | `#B7791F` | 仅剩 N 件 |
| `--bad` | `#F87171` | `#D93A3A` | 失效、错误 |

### 浅色主题

| Token | 值 |
|---|---|
| `--bg` / `--bg-1` / `--bg-2` / `--bg-3` | `#F6F6F9` / `#FFFFFF` / `#F1F2F6` / `#E9EBF1` |
| `--bd` / `--bd-2` | `#E4E6EC` / `#CFD3DC` |
| `--t1` / `--t2` / `--t3` | `#14161C` / `#5A6172` / `#8B93A5` |

**对比度**：正文 `--t1` 对 `--bg` ≥ 12:1；`--t2` ≥ 5.5:1；价格色对底色 ≥ 4.5:1（深色下 `#FF7A3D` 对 `#12141A` 约 7.6:1）。

### 禁用

蓝色主按钮、紫粉渐变、多彩撞色、纯黑 `#000` 文字、纯白 `#fff` 深色底（用 `#0A0B0F` 替代）。

## 3. 字体系统

- **栈**：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif`（不引外部字体）
- **等宽**：`ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace`（仅用于工具名、订单号、色值）

| 用途 | 字号 | 字重 | 字距 |
|---|---|---|---|
| 页面主标题 | 40 | 700 | −0.02em |
| 区块标题 | 20–24 | 600 | −0.01em |
| 商品标题（详情） | 24 | 600 | −0.01em |
| 正文基线 | 14 | 400 | 0 |
| 辅助说明 | 12 | 400 | 0 |
| 价格 | 15 / 18 / 34 | 700 | −0.01em + `tabular-nums` |

- 行高：正文 1.6 / 标题 1.3
- 层级靠**字重 + 字号 + 留白**建立，不用彩色下划线、不用阴影

---

## 4. 空间与形状

- **8pt 网格**：间距取 8 的倍数（4 仅用于图标微调）
- **容器**：`max-width: 1200px`，左右 padding 16px（沿用 v2，不改）
- **圆角**：卡片 `18px` / 面板与弹层 `14px` / 按钮与输入 `10px` / 小控件 `8px` / 标签与头像 full
- **描边**：默认 1px `--bd`；hover 换 `--bd-2` 或 `--brand`
- **阴影**：只用于浮层（浮窗、下拉、吸底卡）：`0 12px 40px rgba(0,0,0,.45)`；卡片**不用阴影**，用描边
- **辉光**：主按钮 hover 用 `0 0 0 1px rgba(109,91,255,.4), 0 10px 36px rgba(109,91,255,.22)`，全站仅此一处

## 5. 组件规范

| 组件 | 规范 |
|---|---|
| 按钮 | 高度 40（大号 48 / 小号 32）；主 `--brand` 白字；价格场景 `--price` 白字；次要 1px 描边；弱化 `--bg-2` 无描边 |
| 输入框 | 高 40，`--bg-2` 底 + 1px `--bd`；focus 换 `--brand` 描边 + 3px `--brand-dim` 光环 |
| 搜索框 | 通栏胶囊（`border-radius: 999px`），主视觉元素 |
| 商品卡 | 图区 `aspect-ratio: 1/1` + `object-fit: cover`；hover 上浮 3px + 图片 `scale(1.04)`；名称两行截断 |
| 标签 | 胶囊，高 24；`--brand-dim` / `--price-dim` / 语义色 14% 底 + 对应前景色 |
| 价格 | 暖橙 + 700 + `tabular-nums`；划线原价用 `--t3` 400 字重 |
| 步骤器 | 描边胶囊，按钮 38×40，数值区 48 宽居中 |
| 表格（后台） | 表头 12px `--t3`；行 hover `--bg-2`；**只留横线**，无竖线无斑马纹 |
| 侧栏（后台） | `--bg-1` 底 + 1px 右描边；激活项 `--brand` 实底白字（替换 AdminLTE 深色默认） |
| 浮窗（客服） | 372×470，`14px` 圆角，1px `--bd-2` 描边 + 浮层阴影；头部品牌色渐变淡出 |
| 消息气泡 | 用户 `--brand` 实底白字右对齐；机器人 `--bg-2` 左对齐；相邻圆角收窄 5px |
| 上下文面板 | 六区块纵向排列，区块间 1px 分隔线；键名 11px `--t3` + 状态圆点，值 12px |

### 动效

- 统一 `transition: 150–200ms cubic-bezier(.2,.7,.2,1)`，只用于颜色 / 描边 / 位移 / 阴影
- 卡片 hover 位移 ≤ 3px；**去掉 v2 的 IntersectionObserver 滚动入场**（深色下淡入观感偏"空"）
- 唯一允许的常驻动画：客服「回答中」状态点的 1.4s 呼吸
- `prefers-reduced-motion: reduce` 时全部关闭

## 7. 落地顺序

1. **底座**：新增 `mall/css/onyx.css`（token + 组件 + 工具类），`header.html` 引入；旧 `common.css` 的 token 段被替换
2. **头部与页脚**：`header.css` + `footer.html` —— 一改全站生效，先验证
3. **首页**：`styles/index.css`（改动最大、观感最直接）
4. **列表 / 详情 / 购物车**：`styles/search.css` `detail.css` `cart.css`
5. **客服**：`css/cs-widget.css` + `styles/cs.css`（**先跑 `CsWidgetGuardTest` / `CsFrontendGuardTest` / `CsXssBrowserIT` 确认没破坏契约**）
6. **订单 / 个人中心 / 登录注册 / 支付**：其余 `styles/*.css`
7. **后台换肤**：`admin/dist/css/main.css`
8. **错误页**：`error/*.html`
9. **主题收敛**：`themes.css` 由 6 套改为深 / 浅 2 套（`header.html` 的主题菜单同步）

- [ ] 深色下所有文字可读，不存在"深灰字压深灰底"
