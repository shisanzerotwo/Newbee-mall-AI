# NewBee Mall WebUI 重设计规格（DESIGN.md）

> 版本 v1.0 · 2026-09-13 · 状态：已确认（方向经用户选定：清爽极简电商 · 全响应式 · 前台+后台）
> 本文件是本次 UI 重设计**唯一视觉依据**：所有 CSS / 模板改动必须能回溯到本文的 token 与组件规范。
> 流程遵循 web-design skill 两阶段：先规格后编码；收尾按反"AI 味"清单与截图验证。

---

## 1. 设计方向

- **关键词**：清爽、极简、留白、卡片化、克制
- **受众**：演示/作品集场景下的通用电商用户；信息优先，装饰最少
- **氛围词**：干净、轻、可信、现代电商（参考气质：京东/Shopify 的白底单强调色体系）
- **原则**：高级 = 克制 + 一致。全站只用一个品牌主色 + 一个价格强调色，其余全部中性灰阶

## 2. 色彩系统（CSS 变量 token，OKLCH 校验对比度）

### 品牌色（青绿 teal，沿用现有品牌色 #1baeae 演进）

| Token | 值 | 用途 | 对比度说明 |
|---|---|---|---|
| `--brand-300` | `#8ad6d6` | focus 光环、选中背景 | 装饰用 |
| `--brand-500` | `#1baeae` | 品牌识别、图标、边框激活 | 白底上仅用于图形/大字号 |
| `--brand-600` | `#119a9a` | 链接、hover | 白底 ≥3.5:1 |
| `--brand-700` | `#0d7f7f` | **主按钮底色、导航激活** | 白字 ≥4.5:1（AA） |
| `--brand-800` | `#0a6060` | 按压态、深色徽标 | — |

### 强调色（价格/促销，暖橙，承接原 #ff6700 记忆）

| Token | 值 | 用途 |
|---|---|---|
| `--accent-500` | `#e8590c` | 价格、促销标签（配粗体/大字号 ≥3:1） |
| `--accent-50` | `#fef0e6` | 促销标签底色 |

### 中性色（正文不用纯黑）

| Token | 值 | 用途 |
|---|---|---|
| `--text-1` | `#1f2328` | 主文字 |
| `--text-2` | `#57606a` | 次要文字 |
| `--text-3` | `#8b949e` | 辅助/占位 |
| `--bg-page` | `#f6f8f9` | 页面底 |
| `--bg-surface` | `#ffffff` | 卡片/表面 |
| `--border` | `#e4e8eb` | 分隔线/描边 |
| `--danger` | `#d1242f` | 错误/删除 |
| `--success` | `#1a7f37` | 成功态 |

**禁用**：蓝色主按钮、紫粉渐变、多彩撞色（反"AI 味"）。

## 3. 字体系统

- **栈**：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Segoe UI", sans-serif`（不引外部字体，中文场景最稳）
- **字号阶梯**（px）：12 辅助 / 13 说明 / **14 正文基线** / 16 小标题 / 18 卡片标题 / 20 区块标题 / 24 页面标题
- **行高**：正文 1.6；标题 1.3
- **价格数字**：`font-variant-numeric: tabular-nums` + 700 字重 + `--accent-500`
- **层级表达**：字重（600 标题）+ 字号 + 留白，不靠彩色下划线/阴影

## 4. 空间与栅格

- **8pt 网格**：所有间距取 8 的倍数（4 仅用于图标与文字微调）
- **容器**：`max-width: 1200px; width: 100%; margin: 0 auto; padding: 0 16px`（替换固定 1226px）
- **区块节奏**：区块间距 40px（桌面）/ 24px（移动）；卡片内边距 16~24px
- **页面底色**：`--bg-page` 浅灰，内容卡片白底区分层次

## 5. 组件规范

| 组件 | 规范 |
|---|---|
| 圆角 | 卡片 8px；按钮/输入框 6px；头像/标签 full |
| 阴影 | 静止 `0 1px 2px rgba(16,24,40,.06)`；hover `0 8px 24px rgba(16,24,40,.10)`；**不堆叠多层柔影** |
| 按钮 | 主：`--brand-700` 白字；次：白底 `--border` 描边；危险：`--danger`；高 40px，hover 加深一档 |
| 输入框 | 高 40px，白底 1px `--border`，focus 换 `--brand-500` 描边 + `--brand-300` 外光环 |
| 商品卡片 | 白底卡片 + 商品图区（`object-fit: cover` 兜底任意比例）+ 名称两行截断 + 价格行 |
| 表格（后台） | 表头浅灰底，行 hover `#f6f8f9`，边框只留横线 |
| 标签/徽标 | 状态色 50 底 + 700 文字的浅底深字方案 |
| 导航（前台） | 白底通栏：logo + 搜索框（主视觉）+ 用户/购物车入口；移动端折叠为汉堡菜单 |
| 侧栏（后台） | 浅色侧栏 + `--brand-700` 激活态，替换 AdminLTE 深色默认 |

## 6. 动效

- 统一 `transition: 150ms ease-out`，只用于颜色/阴影/位移
- 卡片 hover 位移 ≤4px；**禁用**常驻循环动画（后台 particles 背景移除）
- 无滚动视差、无入场动画堆砌

## 7. 响应式断点

| 断点 | 布局 |
|---|---|
| ≥1200px | 桌面：完整导航 + 4 列商品网格 |
| 992–1199px | 容器自适应，商品 3 列 |
| 768–991px | 导航精简，商品 3 列，侧栏类内容下移 |
| <768px | **汉堡导航**，商品 2 列，表单/结算流程单列堆叠，隐藏次要链接 |

后台：沿用 AdminLTE 内建 sidebar 折叠；jqGrid 表格容器 `overflow-x: auto` 防溢出。

## 8. 改造范围

- **前台**：`mall/css/common.css`（token 化重写，保留 .w/.fl/.fr 等旧类名换实现）+ `styles/` 13 文件逐页重写 + `header/footer` 片段与 5 个独立页（login/register/pay-select/alipay/wxpay）+ `error/` 4 页
- **后台**：`admin/dist/css/main.css` 换肤层（CSS 变量覆盖 AdminLTE/Bootstrap primary；DOM 与插件零改动）+ 登录页视觉简化（去 particles）
- **不动**：任何 Java 代码、Controller、jqGrid 列定义、wangEditor、上传逻辑、商品图数据（DB 字段 + D:/upload 外部目录）

## 9. 反"AI 味"清单（收尾逐项自查）

- [ ] 标题不依赖默认字体"裸奔"——用字重/字号层级建立性格
- [ ] 无蓝色主按钮 + 紫粉渐变
- [ ] 圆角/阴影统一成语言，无 20px+ 大圆角 + 柔影堆叠
- [ ] 图标全部来自现有 iconfont（专业图标，无 emoji 当图标）
- [ ] 无假评价/假数据；文案沿用项目真实数据
- [ ] 8pt 网格 + 留白呼吸感，无内容堆叠

## 10. 无障碍

- 正文对比度 ≥4.5:1；大字号/图形 ≥3:1
- focus 态可见（输入框光环、链接 hover/active）
- 语义化：保留原模板标题层级与表单 label

## 11. 暗色模式

本期不做（电商浅色为主，控制范围）；token 已用 CSS 变量隔离，后续可平滑加 `prefers-color-scheme`。

# v2 补充 · 排版与动效「简洁丝滑」（2026-09-14）

> 迭代目标：少一条横栏、多一档留白、处处 150–400ms 微动效。主题系统（6 套）保持兼容。

## 12. 头部合并（单一 sticky 头）
- 原「工具条 + 主导航」两条横栏合并为**一条 sticky 头部**：logo（文字标，主题可换字体）+ 搜索框 + 右侧（主题入口 / 登录·注册 / 购物车 / 后台入口）
- 滚动 >8px 出现投影（sticky + JS 判定），回顶消失
- 移动端：搜索框换行占满，次要链接隐藏

## 13. 留白节奏（8pt 倍数）
- 区块间距 48px（原 36）；卡片内距 16/24；页头与首屏间距 24px
- 卡片名两行截断、简介单行省略——密度降一档

## 14. 动效规范（丝滑但克制）
| 项 | 规格 |
|---|---|
| 全局缓动 | `--ease: cubic-bezier(.2,.6,.2,1)`；快速 150ms / 中速 250ms / 浮现 400ms |
| 卡片 hover | 上浮 2px + 阴影 + 图片 scale(1.03)（统一曲线） |
| 滚动浮现 | 区块/卡片 IntersectionObserver fade-up（位移 16px，400ms，交错 60ms） |
| sticky 头部 | 投影淡入淡出 250ms |
| 平滑滚动 | `scroll-behavior: smooth` |
| 无障碍 | `prefers-reduced-motion: reduce` 时全部动效禁用 |

## 15. 兼容性
- 主题系统：所有新样式走 token，6 套主题自动继承
- 独立头页面（购物车/登录/注册）：保持各自布局，仅继承动效 token
